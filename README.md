# [meowmd](https://uwuclxdy.github.io/meowmd)

**a tiny markdown viewer + editor that autosaves in your browser.**

nothing to install. open the page, type, and it stays.

## what it does
- live preview as you type, with syntax-highlighted code blocks
- a table of contents that follows the preview
- per-tab autosave to localstorage; nothing leaves your browser
- dark and light themes
- a drawer layout that works on a phone

## why
no account, no server, no build step. it is a page and a few files, so it stays fast and private.

## development
plain html/css/js served from github pages. edit `index.html`, `style.css`, `script.js`, then run any static server to preview.
